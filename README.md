# glassbox
GlassBox is a web-based educational project designed to visualize all phases of a
compiler. Traditional compiler implementations work as black boxes where users only
see the final output. GlassBox breaks this limitation by exposing and visually
representing each internal phase of compilation, making it easier for students to
understand complex compiler concepts

The main objectives of GlassBox are:
• To implement all major phases of a compiler
• To visualize each compiler phase in an interactive manner
• To simplify understanding of compiler internals for students
• To provide a modular and extensible compiler framework
• To ensure platform independence using web technologies
